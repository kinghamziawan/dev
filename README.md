# Weather App

A fully functional weather app built with HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Get weather using your current location
- Current weather details:
  - Temperature
  - Feels-like temperature
  - Humidity
  - Wind speed
  - Conditions
- 5-day forecast

## Run locally
Because this app uses browser APIs and fetch calls, run it with a local web server.

### Python
```bash
python3 -m http.server 8080
```
Then open:
`http://localhost:8080`
